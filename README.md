# ACADI — helloacadi.com

Free educational platform for parents of special-needs kids (ages 2–15) in Lebanon.
Arabic / English / French, RTL-ready. Parent Classroom, Free Printables, Parent Resources, Support.

## Stack
- Single-file app: `index.html` (vanilla JS, GSAP + Lenis for motion)
- Character art and icons in `img/`
- Hosting: Netlify (`netlify.toml` included)
- Backend/admin: Supabase (in progress)

## Local preview
Open `index.html` in a browser, or `npx serve .`
